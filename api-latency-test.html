Time API Latency Test

Source OK / Total Min (ms) Avg (ms) Median (ms) Max (ms)
Measures round-trip time (request sent → response fully read) for each time source used by the world clock's sync fallback chain. Requests to each source run sequentially, one source at a time, so sources don't compete for bandwidth with each other. Lower round-trip time generally means a tighter, more accurate offset correction. Results depend heavily on your network and location, so re-run a few times before drawing conclusions.
